## 🎯 ویژگی‌های کلیدی دوره

کدنویسی سنتی در حال گذار به **وایب کدینگ (Vibe Coding)** است؛ جایی که شما معمار و کارگردان هستید و ایجنت هوش مصنوعی نقش بازوی پیاده‌سازی را دارد. این دوره:
- **فارسی، روان و تخصصی** — تمامی مفاهیم عمیق و اصطلاحات روز با معادل‌سازی استاندارد و توضیحات شهودی.
- **تمرکز روی ابزار رسمی Claude Code** — آموزش کار با CLI بومی Anthropic، ساختار حافظه (`CLAUDE.md`)، معکوس‌سازی کدهای ناشناخته و ابزارهای خط فرمان.
- **همراه با آزمون‌های مفهومی (Quizzes)** — هر درس همراه با سوالات ۴ گزینه‌ای و تحلیل دقیق چرایی درستی یا نادرستی پاسخ‌ها.
- **پروژه‌محور و عملی** — از تسک‌های کوچک تک‌فایلی تا پیاده‌سازی اپلیکیشن‌های کامل فول‌استک، ریفکتورینگ و حل باگ‌های پیچیده.
- **چیت‌شیت و واژه‌نامه اختصاصی** — خلاصه تمام دستورات خط فرمان، کلیدهای میانبر، و دیکشنری اصطلاحات مدرن مهندسی هوش مصنوعی.

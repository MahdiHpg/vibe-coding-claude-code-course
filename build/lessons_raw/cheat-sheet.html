Install & start

Get Claude Code onto your machine and open a session in the right folder.

npm install -g @anthropic-ai/claude-code

Installs the Claude Code CLI globally with npm. Anthropic also ships a native installer script; either route ends with a claude command on your PATH.

npm install -g @anthropic-ai/claude-code
Course 01 · Install the CLI
claude

Starts an interactive session in the current directory. The folder you launch from is the project the agent can see and edit.

cd my-app && claude
Dictionary · SessionCourse 01 · Your First Conversation
claude "prompt"

Starts a session and sends the first message immediately.

claude "explain the folder structure and find the entry point"
Course 01 · Your First Conversation
claude -p "prompt"

Print mode: runs one prompt non-interactively, prints the answer, exits. The basis of every script and CI job.

claude -p "list the TODO comments in src/"
Dictionary · Headless mode
claude --continue

Reopens the most recent session in this directory with its full context. Short form: -c.

claude -c
Dictionary · Session
claude --resume

Shows a picker of past sessions in this directory so you can reopen one. Short form: -r; pass a session id to skip the picker.

claude -r
Dictionary · Handoff
--model <name>

Picks the model for the session. Aliases like sonnet and opus work, as do full model ids. You can also switch mid-session with /model.

claude --model opus
Dictionary · Model
--add-dir <path>

Grants the agent access to an extra directory outside the one you launched from, for monorepos or shared packages.

claude --add-dir ../shared-lib
Dictionary · Filesystem
claude update · claude --version

Updates to the latest release, or prints the version you are on. Run update before filing a bug.

claude update

Modes & permissions

What the agent may do without asking, from read-only to fully unattended.

Default (ask)

Reads and searches freely; asks before every file edit and every command that changes state.

Dictionary · Permission request
Accept edits

Auto-approves file edits in the project; still asks before shell commands. Good for a tight loop where you review diffs after.

Dictionary · Permission mode
Plan mode

Read-only: the agent investigates and proposes a plan you approve before anything is edited.

claude --permission-mode plan
Dictionary · Plan modeCourse 01 · Plan Mode
--dangerously-skip-permissions

Skips every prompt. Only inside a sandbox or container with no secrets and nothing you cannot restore.

Dictionary · Sandbox
--allowedTools · --disallowedTools

Pre-approves or blocks specific tools for the session, with optional argument patterns.

Hooks

Shell commands the harness runs on events. Deterministic, unlike an instruction the model might skip.

PreToolUse

Runs before a tool call. Exit code 2 blocks the call and sends your stderr to the model as the reason.

Dictionary · Tool callCourse 01 · Hooks: Pre and Post Tool
PostToolUse

Runs after a tool call succeeds. The classic use: format the file that was just edited.

{ "matcher": "Edit|Write", "hooks": [{ "type": "command", "command": "npx prettier --write \"$FILE\"" }] }
Dictionary · Tool resultCourse 01 · Hooks: Pre and Post Tool
UserPromptSubmit

Runs when you send a message, before the model sees it. Can add context or block the prompt.

Notification

Runs when Claude Code wants your attention, such as waiting for permission. Wire it to a desktop notification.

Stop · SubagentStop

Runs when the agent (or a subagent) finishes a turn. Use it to require green tests before it is allowed to stop.

Dictionary · Automated check
PreCompact

Runs before compaction, so you can save the transcript or inject what must survive.

Dictionary · Compaction
SessionStart

Runs when a session starts or resumes. Good for loading environment context.

Dictionary · Session
matcher

Filters which tool names a hook applies to; a plain name or a regex such as Edit|Write. Omit it to match everything.

Dictionary · Tool
Hook input & exit codes

Hooks receive JSON on stdin (tool name, input, session, cwd). Exit 0 allows, exit 2 blocks with feedback, anything else is a non-blocking error shown to you.

MCP

Plug external tools into the session: databases, browsers, SaaS APIs, your own servers.

claude mcp add <name> -- <command>

Adds a local stdio server. Everything after -- is the command that starts it.

claude mcp add github -- npx -y @modelcontextprotocol/server-github
Dictionary · MCPCourse 01 · MCP Servers
claude mcp add --transport http <name> <url>

Adds a remote HTTP server; use --transport sse for servers that still speak SSE. Authenticate with /mcp.

claude mcp add --transport http linear https://mcp.linear.app/mcp
Dictionary · MCP
claude mcp list · get · remove

Lists configured servers, shows one, or removes one.

claude mcp remove github
-s local | project | user

Scope: local is this folder for you only, project writes .mcp.json for the team, user applies everywhere.

claude mcp add -s project ...
mcp__<server>__<tool>

How MCP tools are named once connected; use the same names in permission rules and --allowedTools.

"allow": ["mcp__github__create_issue"]

Headless & scripting

Run Claude Code from scripts, cron and CI with no terminal UI.

claude -p "prompt"

One prompt, one answer, exit. Combine with the flags below for automation.

claude -p "summarise the last 10 commits"
Dictionary · Headless mode
--output-format text | json | stream-json

Plain text (default), a single JSON result with usage and cost, or streamed JSON events for tooling.

claude -p "..." --output-format json
Dictionary · Headless mode
--max-turns <n>

Caps the number of agentic turns so a runaway task cannot loop forever.

--max-turns 15
Dictionary · Turn
--append-system-prompt

Adds instructions to the default system prompt for this run without replacing it.

--append-system-prompt "Only touch files under packages/api"
Dictionary · System prompt
stdin piping

Anything piped in becomes part of the prompt context.

CI usage

Set ANTHROPIC_API_KEY, pick an explicit permission mode or allow-list, and let the run end in a pull request rather than a merge. Anthropic publishes an official GitHub Action.

claude -p "fix the failing test" --allowedTools "Read" "Edit" "Bash(npm test)"

Worktrees & parallel work

Run several agents on one repo without them stepping on each other.

git worktree add ../repo-feature -b feature

Creates a second checkout of the repo on a new branch, sharing one .git. Start a separate claude session inside it.

git worktree add ../my-app-auth -b feat/auth && cd ../my-app-auth && claude
Dictionary · Worktree
One agent per worktree

Each session gets its own files and its own branch; merge the results through pull requests.

Dictionary · AFK
git worktree list · remove

Lists active worktrees and deletes one when the branch is merged. Worktrees cost disk; clean up.

git worktree remove ../my-app-auth
Dictionary · Worktree
Built-in worktree support

Newer builds can create an isolated worktree for a task themselves; check claude --help for the current flag.

Claude Code FAQ

The questions people search before they type their first prompt.

What is Claude Code?

Claude Code is Anthropic's agentic coding tool that runs in your terminal. You describe what you want in plain language; it reads your codebase, edits files, runs commands and tests, and reports back, asking permission for anything risky.

How do I install Claude Code?

Install it with npm (npm install -g @anthropic-ai/claude-code) or Anthropic's native installer, then run claude inside a project folder and sign in with a Claude subscription or an API key.

Is Claude Code free?

The tool itself is free to install. Usage is metered through Claude subscription plans or API billing; see anthropic.com for current pricing and plan limits.

Claude Code vs Cursor: which should I use?

Claude Code is a terminal agent that works through your whole project autonomously; Cursor is an AI-native editor where you stay in the file. Many people use both. Our comparison page walks through the tradeoffs.

What is CLAUDE.md?

CLAUDE.md is the project memory file Claude Code loads at the start of every session: build and test commands, conventions and gotchas. Generate a starter with /init and keep it short.

How do I run Claude Code in CI?

Use print mode (claude -p) with an explicit permission allow-list, an API key in the environment, and --output-format json if a script consumes the result. Anthropic also publishes an official GitHub Action. Have the run end in a pull request, not a merge.
